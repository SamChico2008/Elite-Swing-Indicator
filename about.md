# Elite Swing Indicator

The most advanced, professional-grade gravity HUD for Swing Copter mode in Geometry Dash.

### Key Features
- **Elite Vector Rendering**: Crystal clear indicators using custom `CCDrawNode` logic (no pixelation).
- **Dual Mode Support**: Fully reactive indicators for both players in Dual mode, displaying their respective primary colors.
- **Visual Shockwave**: Dynamic expanding ring effect on gravity flip for tactical feedback.
- **Velocity Tracker**: Integrated reactive bar showing your vertical momentum in real-time.
- **Pro-Friendly Performance**: Built using Geode's event-driven architecture for zero impact on FPS.

### Customization
Tailor your experience via the Geode settings menu:
- Adjust **Scale** and **Vertical Displacement**.
- Toggle the **Velocity Tracker** and individual HUD elements.
- Select from multiple indicator styles (v1.1.0 update).

Designed for players who want a sleek, modern interface that enhances gameplay without cluttering the screen.
